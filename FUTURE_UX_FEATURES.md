# Future UX Features for PokéGO Search String Builder

This document outlines potential User Experience (UX) and Quality of Life (QoL) features that can be implemented in the future to improve the PokéGO Search String Builder tool.

## 1. Copy to Clipboard
*   **Description:** A prominent button near the generated string output to instantly copy it.
*   **Benefit:** Makes it ready to paste directly into the Pokémon GO app without manual highlighting.

## 2. Save/Bookmark Strings
*   **Description:** Allow users to save their frequently used, complex search strings.
*   **Implementation Idea:** Use local storage (`localStorage`) to persist saved strings across sessions. Provide a UI list to select, edit, or delete them.
*   **Benefit:** Great for players who use specific strings repeatedly (e.g., for Community Days, PvP IV checking).

## 3. Shareable Links
*   **Description:** Update the URL with query parameters as the user builds the string.
*   **Benefit:** Allows users to easily share specific search setups with friends or communities by copying the URL.

## 4. Custom Text Input
*   **Description:** A text box that allows users to manually type or paste in custom tags, nicknames, or specific search parameters not yet in the builder.
*   **Benefit:** Provides flexibility for advanced users or for combining generated strings with personal tags.

## 5. Multi-language Support
*   **Description:** Allow users to switch the language of the search terms.
*   **Reasoning:** Search terms in Pokémon GO are localized (e.g., `shiny` in English is `schillernd` in German, `schmuck` in another, etc.).
*   **Benefit:** Significantly increases the tool's usability for the international Pokémon GO player base.
